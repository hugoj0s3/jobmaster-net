# JobMaster.SqlBase
### Shared base for the SQL storage providers of JobMaster .Net.

📚 [Documentation](https://docs.jobmaster.hugoj0s3.dev)

This package contains the common implementation used by the PostgreSQL, MySQL and SQL Server providers.
You don't need to install it yourself: it comes with those providers. Reference it directly only to build your own SQL database provider.

```bash
dotnet add package JobMaster.SqlBase
```
